# Goals

This document defines the concrete, measurable goals for **Money Making
Machines**.

## Primary Goals

### 1. Build a comprehensive encyclopedia of automated income methods

- Document at least 20 distinct money-making methods
- Each method must have a full step-by-step guide
- Each method must include realistic income estimates, time investment, and
  risk level
- Cover diverse categories: passive income, trading bots, freelance automation,
  content monetization, bandwidth sharing, and more

### 2. Make every guide executable in-browser

- Every guide must have a working "Start making money" button
- Every individual step must have its own "Run this step" button
- The automation log must clearly show exactly what each step does, with
  timestamps
- No step may run silently — users always see what is happening

### 3. Keep everything Public Domain

- All code, content, and guides are licensed under the Unlicense
- No contributor license agreements required
- No proprietary dependencies in the automation code itself
- Third-party tools referenced in guides may have their own licenses, which
  are always disclosed

### 4. Deploy and maintain a live GitHub Pages website

- The website is always live and accessible at the GitHub Pages URL
- Every merge to `main` automatically redeploys the website
- The site is fast, accessible, and works without JavaScript for basic reading

### 5. Support community contributions

- Clear contributing guidelines
- Automated CI checks (lint, format) to maintain code quality
- Any contributor can add a new method page following the established template

## Success Metrics

| Goal                           | Target                                    |
| ------------------------------ | ----------------------------------------- |
| Number of documented methods   | 20+ (starting with 6 in proof-of-concept) |
| In-browser automation coverage | 100% of documented methods                |
| CI pass rate                   | 100% on all PRs                           |
| License compliance             | 100% Unlicense on all original content    |
| Deployment uptime              | GitHub Pages auto-deploy on every push    |
