Freelance Job Alerts

Be the first to apply to new freelance jobs by automating alerts from Upwork, Freelancer and PeoplePerHour — using each platform's built-in saved-search notifications plus RSS where it still works. Respond faster = win more contracts.

Active Beginner

Overview

Freelance platforms post new jobs every few minutes. The contractors who respond within the first hour get hired far more often. This guide sets up an alert system that notifies you the moment a matching job is posted — using each platform's own saved-search notifications, the RSS feeds that still work, and (optionally) managed monitoring services.

⚠️ RSS update (2024–2026): Upwork discontinued its public job RSS feeds in August 2024 (the old /ab/feed/jobs/rss endpoint now returns 410 Gone). For Upwork you now rely on its built-in saved search email/mobile alerts or a third-party service (Vollna, GigRadar). Freelancer.com still publishes an RSS feed and PeoplePerHour offers email alerts.

Realistic expectations: This won't automate applying or writing proposals (which would risk account bans). It gives you a genuine competitive edge by ensuring you see every relevant job instantly.

⚠️ ToS note: Reading public RSS feeds and using a platform's own alert settings is always allowed. Automated proposal submission or account creation violates most platform ToS. This guide only automates the notification side.

Step-by-step Guide

1

Identify your keywords & skills

Write down 5–10 search terms that describe the work you can do. Examples: react developer, python automation, wordpress plugin, logo design.

Specific keywords get fewer but better-matched results. Broad keywords get more noise. Start specific.

or write your keywords in a text file
2

Turn on each platform's native saved-search alerts

The most reliable, always-allowed alert source is each platform's own saved-search notification — it survived every API/RSS change:

  • Upwork: run a search with your keyword, click Save search, then enable email and push notifications in the mobile app. (Upwork's public RSS feed was retired in 2024, so this is now the primary route.)
  • Freelancer.com: still publishes an RSS feed of the newest projects at https://www.freelancer.com/rss.xml — and offers per-skill email alerts in your account settings.
  • PeoplePerHour: set up an email alert from the freelance-jobs search page for each keyword.

Test the Freelancer RSS feed by opening the URL in a browser — you should see XML with the newest projects. Filter it by keyword in your RSS reader (next step).

or set up saved-search alerts manually
3

Choose a notification method

Pick one or more of these free options:

  • RSS reader with alerts — Feedly, Inoreader, or the free RSSnoti.fy service sends an email on each new item
  • IFTTT / Make (formerly Integromat) — free plans can monitor RSS and send push notifications or emails
  • Self-hosted n8n — open source workflow tool, poll RSS every 5 minutes, send Telegram/Slack/email
  • GitHub Actions — free CI server that can poll RSS on a schedule and email you
  • Managed Upwork monitors — because Upwork no longer offers RSS, services like Vollna and GigRadar watch Upwork in near-real-time and push filtered alerts (free tiers available)
or choose a tool from the list above
4

Set up RSS-to-email with IFTTT (no code)

IFTTT is the easiest no-code option. Create an Applet: Trigger: New item in RSS feed → Action: Send me an email.

  1. Go to ifttt.com/create
  2. Click If This → search "RSS Feed" → "New feed item"
  3. Enter your Freelancer RSS URL (https://www.freelancer.com/rss.xml) — add a keyword filter in the applet if your reader supports it
  4. Click Then That → search "Email" → "Send me an email"
  5. Save and enable the Applet
or follow the steps above manually
5

Respond fast & write strong proposals

When you receive an alert, open the job immediately. A great proposal:

  • Starts with a specific reference to their project (not a template)
  • Shows 1–2 relevant past projects or skills
  • Ends with a clear next step ("I can start Monday")
  • Is under 200 words

AI tools like Claude or ChatGPT can help draft a first proposal which you then personalise — cutting writing time from 20 minutes to 5 minutes.

or write your proposals manually
