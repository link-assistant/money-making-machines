Microsoft Rewards

Earn Microsoft Reward points by completing daily activities and Bing searches, then redeem them for gift cards, Xbox credits, or PayPal cash.

Passive Beginner

Overview

Microsoft Rewards is an official Microsoft program. You earn points by searching Bing, completing daily quizzes, and shopping at Microsoft Store. Points are redeemable for Amazon/Xbox/Starbucks gift cards, charitable donations, or PayPal cash.

Realistic earnings: $5–$10/month per account in gift card value with consistent daily activity. Fully automated with the open-source Microsoft-Rewards-bot.

⚠️ Terms of Service: Microsoft Rewards ToS prohibits automation. Using a bot risks account suspension. This guide describes the manual process first; automation is described for educational purposes. Use at your own risk.

Step-by-step Guide

1

Sign up for Microsoft Rewards

Microsoft Rewards is free. You need a Microsoft account (you may already have one if you use Outlook, Xbox, or Windows).

Sign up at rewards.microsoft.com and link it to your Bing searches by logging into Bing.

or visit the site above manually
2

Understand how points work

The main ways to earn points:

  • PC searches: 3 points per search, up to 90 points/day (30 searches)
  • Mobile searches: 3 points per search, up to 60 points/day (20 searches)
  • Daily set activities: 10–45 points — quizzes, polls, Microsoft News
  • Punch cards & streaks: bonus points for consecutive days

Redemption rate: typically 1,300–1,500 points = $1 gift card (varies by region and card type).

or log in to see your points
3

Complete daily activities manually

The fastest manual routine takes under 5 minutes per day:

  1. Go to rewards.microsoft.com and complete the "Daily Set" activities (quizzes, polls)
  2. Open Bing and make 30 searches on PC (search random words, hit enter)
  3. Open the Microsoft Rewards app on your phone and make 20 mobile searches
or do it manually following the steps above
4

Optional: automate with Microsoft-Rewards-bot

The open-source Microsoft-Rewards-bot (MIT) automates all daily activities using a headless browser. It supports multiple accounts, Telegram notifications, and scheduling. 

# Install
git clone https://github.com/farshadz1997/Microsoft-Rewards-bot.git
cd Microsoft-Rewards-bot
pip install -r requirements.txt

# Configure
cp accounts.json.example accounts.json
# Edit accounts.json — add your Microsoft account email and password

# Run (use --visible to watch the browser)
python main.py
⚠️ Risk: Automation may trigger Microsoft's bot detection. Use a secondary Microsoft account, not your main one, if you try this.
or skip and do it manually
5

Redeem points for gift cards

Once you reach the minimum threshold (usually 1,300–5,000 points depending on the reward), go to the Rewards catalogue and redeem:

  • Amazon gift cards (US, UK, CA, DE…)
  • Starbucks, Target, Nike gift cards
  • Xbox Game Pass, Xbox credits
  • Charitable donations
  • Sweepstakes entries
or browse manually at rewards.microsoft.com
