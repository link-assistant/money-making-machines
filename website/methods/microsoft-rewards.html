Microsoft Rewards

Earn Microsoft Reward points by completing daily activities and Bing searches, then redeem them for gift cards, Xbox credits, or PayPal cash.

Passive Beginner

Overview

Microsoft Rewards is an official Microsoft program. You earn points by searching Bing, completing daily quizzes, and shopping at Microsoft Store. Points are redeemable for Amazon/Xbox/Starbucks gift cards, charitable donations, or PayPal cash.

Realistic earnings: roughly $3–$7/month per account in gift-card value with consistent daily activity. Microsoft has trimmed several regional reward values and tightened anti-abuse enforcement through 2025–2026, so treat this as pocket money, not a serious income stream.

⚠️ Automation is risky — do this manually. Microsoft Rewards' Terms of Service explicitly prohibit automated searching, and Microsoft has become far more aggressive at detecting it: accounts caught farming are commonly permanently banned and accrued points forfeited. The well-known older bots have already been taken down or abandoned — farshadz1997/Microsoft-Rewards-bot was disabled by GitHub, and charlesbel/Microsoft-Rewards-Farmer was archived in 2024. We recommend the manual routine below (it takes ~5 minutes a day). Any automation is described for educational purposes only — use at your own risk on a throwaway account, never your primary Microsoft account.

Step-by-step Guide

1

Sign up for Microsoft Rewards

Microsoft Rewards is free. You need a Microsoft account (you may already have one if you use Outlook, Xbox, or Windows).

Sign up at rewards.microsoft.com and link it to your Bing searches by logging into Bing.

or visit the site above manually
2

Understand how points work

The main ways to earn points:

  • PC searches: 3 points per search, up to 90 points/day (30 searches)
  • Mobile searches: 3 points per search, up to 60 points/day (20 searches)
  • Daily set activities: 10–45 points — quizzes, polls, Microsoft News
  • Punch cards & streaks: bonus points for consecutive days

Redemption rate: typically 1,300–1,500 points = $1 gift card (varies by region and card type).

or log in to see your points
3

Complete daily activities manually

The fastest manual routine takes under 5 minutes per day:

  1. Go to rewards.microsoft.com and complete the "Daily Set" activities (quizzes, polls)
  2. Open Bing and make 30 searches on PC (search random words, hit enter)
  3. Open the Microsoft Rewards app on your phone and make 20 mobile searches
or do it manually following the steps above
4

Optional (high risk): automation tools

The older Python bots that most guides point to are gone — farshadz1997/Microsoft-Rewards-bot was disabled by GitHub and charlesbel/Microsoft-Rewards-Farmer was archived in 2024. The one project still actively maintained in 2026 is TheNetsky/Microsoft-Rewards-Script (GPL-3.0, TypeScript + Playwright). It automates the daily set and searches and supports multiple accounts and Telegram notifications. 

# Requires Node.js 18+ and Git
git clone https://github.com/TheNetsky/Microsoft-Rewards-Script.git
cd Microsoft-Rewards-Script
npm install
npx playwright install chromium

# Configure — copy the sample account/config files and add your details
cp src/accounts.example.json src/accounts.json
# Edit src/accounts.json and src/config.json

# Build and run
npm run build
npm start
⚠️ Real ban risk: Microsoft actively detects automated activity and permanently bans accounts caught farming, forfeiting any accrued points. Only ever try this on a throwaway account you don't care about — never your primary Microsoft account. The manual routine in Step 3 carries no such risk.
or skip and do it manually
5

Redeem points for gift cards

Once you reach the minimum threshold (usually 1,300–5,000 points depending on the reward), go to the Rewards catalogue and redeem:

  • Amazon gift cards (US, UK, CA, DE…)
  • Starbucks, Target, Nike gift cards
  • Xbox Game Pass, Xbox credits
  • Charitable donations
  • Sweepstakes entries
or browse manually at rewards.microsoft.com
