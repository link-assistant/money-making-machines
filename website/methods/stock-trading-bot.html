Stock Trading Bot

Develop, backtest, and run algorithmic trading strategies on stocks using open-source Python frameworks — no expensive subscriptions required.

Active Advanced

Overview

Algorithmic trading uses coded rules to execute buy and sell orders automatically. The main open-source frameworks for stock trading are:

  • Backtrader (GPL-3.0, ~22K stars) — still the most popular Python backtesting/live-trading framework, but note its original author stopped active development around 2018; it works well and the community is large, yet it receives few updates
  • backtesting.py (AGPL-3.0, ~8K stars) — a lighter, actively-maintained alternative to Backtrader with fast vectorised backtests and built-in optimisation
  • NautilusTrader (LGPL-3.0, ~23K stars) — a modern, high-performance, actively-developed platform for backtesting and live algorithmic trading (Python + Rust core)
  • QuantConnect LEAN (Apache-2.0) — C#/Python engine supporting stocks, futures, options, forex, and crypto on 50+ data sources
  • Zipline-reloaded (Apache-2.0) — the maintained fork of Quantopian's now-abandoned Zipline; Pandas-based event-driven backtesting that integrates with Alpaca for live trading
⚠️ Major risk warning: Stock trading carries the risk of losing all invested capital. Overfitting in backtesting is extremely common — a strategy that looks great on historical data may lose money live. Never trade with money you cannot afford to lose. This guide is educational only.

Step-by-step Guide

1

Choose a broker with a free API

You need a brokerage that provides a free programmatic API. Commission-free options with good Python support:

  • Alpaca — alpaca.markets — commission-free US stocks/ETFs, free paper trading API
  • Interactive Brokers — interactivebrokers.com — advanced, low fees, good API, requires minimum balance

Start with Alpaca's paper trading (simulated) account — no real money required.

or choose a broker manually
2

Install a backtesting framework

Backtrader is the most beginner-friendly Python framework and is still widely used, even though it is no longer actively developed: 

pip install backtrader
pip install pandas yfinance matplotlib

yfinance provides free historical stock data from Yahoo Finance for backtesting.

Prefer something actively maintained? Swap in backtesting.py (pip install backtesting) for a lighter, faster API, or NautilusTrader for a production-grade event-driven platform. The rest of this guide uses Backtrader, but the workflow is the same in each.

or run the commands above manually
3

Write your first strategy

A simple moving average crossover strategy is the classic starting point. Create strategy.py: 

import backtrader as bt
import yfinance as yf

class SmaCross(bt.Strategy):
    params = dict(fast=10, slow=30)

    def __init__(self):
        sma_fast = bt.ind.SMA(period=self.p.fast)
        sma_slow = bt.ind.SMA(period=self.p.slow)
        self.crossover = bt.ind.CrossOver(sma_fast, sma_slow)

    def next(self):
        if not self.position:
            if self.crossover > 0:       # fast crosses above slow
                self.buy()
        elif self.crossover < 0:         # fast crosses below slow
            self.sell()

# Load data
data_df = yf.download('AAPL', start='2020-01-01', end='2024-01-01')
data = bt.feeds.PandasData(dataname=data_df)

# Run backtest
cerebro = bt.Cerebro()
cerebro.addstrategy(SmaCross)
cerebro.adddata(data)
cerebro.broker.setcash(10000)
cerebro.run()
cerebro.plot()
or write the code above manually
4

Evaluate backtest results carefully

Don't trust a single backtest. Healthy metrics to look for:

  • CAGR > 15%/year (above buy-and-hold)
  • Max drawdown < 20% (how much you could lose peak-to-trough)
  • Sharpe ratio > 1.0 (risk-adjusted return)
  • Out-of-sample test: hold out 20–30% of data and test the strategy on data it never saw

A strategy that only works on in-sample data is likely over-fitted. Test across multiple time periods and multiple tickers.

or evaluate manually
5

Paper-trade for at least one month

Use Alpaca's paper trading API to run your strategy in real market conditions with fake money. Install the Alpaca SDK: 

pip install alpaca-py

# In your strategy, replace the yfinance data feed with Alpaca's live feed
# and use alpaca-py to submit orders — see Alpaca docs for examples

Alpaca paper accounts start with a default $100,000 virtual balance (configurable in the dashboard), so you can test position-sizing realistically. Monitor real-time performance for at least 20–30 trading days before committing real capital.

or set up paper trading manually
6

Go live with small capital

If paper trading is consistently profitable, switch to a live Alpaca account. Start with a small amount (e.g., $500–$1000) — enough to be meaningful but not enough to cause significant harm if the strategy fails.

Set up alerts and monitoring so you know immediately if something goes wrong (e.g., unexpected large trades, errors).
