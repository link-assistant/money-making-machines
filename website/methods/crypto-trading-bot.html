Crypto Trading Bot

Run Freqtrade, the leading open-source crypto trading bot, to automate buy and sell decisions based on technical strategies.

Active Intermediate

Overview

Freqtrade is a free, open-source crypto trading bot written in Python (GPL-3.0, ~51 000 GitHub stars as of mid-2026). It supports 100+ exchanges via the CCXT library, has a built-in backtester, a web UI, Telegram integration, and an optional ML module (FreqAI).

Realistic expectations: A well-tuned strategy may earn 1–5% per month in favourable markets. Poorly tuned strategies can lose money. Always start with paper trading (simulated trades) before risking real funds.

⚠️ Risk warning: Crypto trading involves significant financial risk. Only trade with money you can afford to lose entirely. Past backtest results do not guarantee future live performance.

Step-by-step Guide

1

Install prerequisites

You need Python 3.10+ and Git installed. On most systems these are already present. Verify with: 

python3 --version   # should be 3.10 or higher
git --version

Alternatively, use the official Docker image to skip Python setup entirely (recommended for beginners).

or run the commands above manually
2

Install Freqtrade

The quickest method uses the official install script:

# Clone the repository
git clone https://github.com/freqtrade/freqtrade.git
cd freqtrade

# Run the install script (Linux / macOS / WSL)
./setup.sh -i

Docker alternative: 

docker pull freqtradeorg/freqtrade:stable
# Then follow Docker quickstart at https://www.freqtrade.io/en/stable/docker_quickstart/
or run the commands above manually
3

Create a configuration file

Generate a starter config using the wizard. It walks you through exchange selection, trading pair, stake currency, and risk settings: 

freqtrade new-config --config config.json

Set max_open_trades to a small number (e.g. 3) and stake_amount to a fixed USD amount you are comfortable risking per trade.

or run the command above manually
4

Download historical data & backtest a strategy

Freqtrade ships with several sample strategies. Download OHLCV data and run a backtest before going live: 

# Download 3 months of data for BTC/USDT on Binance
freqtrade download-data --exchange binance --pairs BTC/USDT --timeframe 1h --days 90

# Backtest the built-in SampleStrategy
freqtrade backtesting --strategy SampleStrategy --config config.json

Review the backtest report: look at Profit factor, Win rate, and Max drawdown.

or run the commands above manually
5

Run the bot in paper-trading mode

Paper trading simulates real market conditions with fake money. Run it for at least two weeks before risking real funds: 

freqtrade trade --strategy SampleStrategy --config config.json --dry-run

Open the web UI at http://localhost:8080 to watch trades in real time.

or run the command above manually
6

Go live (real trading)

Once satisfied with paper-trading results, add your exchange API key (read + trade permissions, no withdrawal) to config.json and remove --dry-run: 

freqtrade trade --strategy SampleStrategy --config config.json

Set up a Telegram bot for notifications: Telegram integration docs.

or configure manually
